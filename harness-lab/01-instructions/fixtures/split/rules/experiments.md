# 실험 기록 규칙

## 결과를 적을 때 반드시 남길 것
- 모델 ID (예: `claude-opus-5-5`), 실행 날짜, 주요 하이퍼파라미터, 시드.
- 실행한 정확한 명령 한 줄. 예: `python reason-network/run_relay.py --seed 42 --model claude-opus-5-5`.
- 스크립트 경로와 커밋 해시.
- 숫자를 인용할 때는 출처(논문, 링크, 스크립트 경로)를 붙인다.

## 주제 폴더 README의 순서
1. 목적: 이 실험이 답하려는 질문 한 문장.
2. 실행 방법: 설치와 실행 명령.
3. 결과 요약: 표 하나와 결론 세 줄 이내.
4. 한계: 표본 수, 재현하지 못한 부분, 다음에 확인할 것.

## 비교 실험
- 기준선(baseline)과 변경안을 같은 시드, 같은 입력으로 돌린다.
- 한 번에 한 변수만 바꾼다. 두 개 이상 바꿨다면 README에 그렇게 적는다.
- 차이를 말할 때는 절대값과 비율을 함께 적는다. 예: 2,925 → 2,440 토큰 (16.6% 감소).

## 실패도 기록한다
- 기대와 다르게 나온 결과도 지우지 말고 "관찰"로 남긴다.
- 중단한 실험은 중단 이유와 마지막 상태를 적는다.
