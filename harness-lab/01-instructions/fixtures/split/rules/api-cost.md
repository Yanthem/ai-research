# 유료 API 호출 규칙

## 호출 전에
- 입력 토큰은 `client.messages.count_tokens(...)`로 센다. OpenAI 토크나이저(tiktoken)로 Claude 토큰을 세지 않는다.
- 예상 비용 = 입력 토큰 × 입력 단가 + 최대 출력 토큰 × 출력 단가. 실행 전에 이 값을 출력한다.
- 반복 호출은 횟수를 곱한 총액을 먼저 보여 주고, 사용자가 확인한 뒤 돌린다.

## 단가 표 (1M 토큰당 달러, 2026-11-24 기준. 바뀔 수 있으니 공식 가격표를 확인)
| 모델 | 입력 | 출력 |
|---|---|---|
| claude-opus-5-5 | 4.00 | 20.00 |
| claude-sonnet-5-5 | 2.00 | 10.00 |
| claude-haiku-5-5 | 0.10 | 0.50 |

## 줄이는 방법
- 바뀌지 않는 긴 앞부분(시스템 프롬프트, 문서)은 프롬프트 캐싱을 쓴다.
- 급하지 않은 대량 작업은 Batch API를 쓴다.
- 실험 루프에는 `--max-calls` 인자를 두어 상한을 건다.

## 키 관리
- 키는 `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` 환경 변수나 `.env`에서만 읽는다.
- 로그나 예외 메시지에 키나 요청 헤더를 찍지 않는다.
