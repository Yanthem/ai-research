# 논문 노트 규칙

## 파일 위치와 이름
- `papers/<arXiv-ID 또는 짧은-이름>.md`. 예: `papers/2307.03172.md`, `papers/lost-in-the-middle.md`.
- 같은 논문의 노트는 한 파일에만 둔다. 이미 있으면 그 파일에 덧붙인다.

## 노트 양식
```
# <논문 제목>
- 저자, 연도, 링크
- 한 줄 요약:
## 문제
## 방법
## 핵심 결과 (숫자는 표/그림 번호와 함께)
## 우리 연구회에 주는 시사점
## 의문점
```

## 쓰는 방법
- 숫자는 논문에 있는 그대로 옮기고, 표나 그림 번호를 붙인다. 예: "Table 1: 중앙값 실행 시간 98.57초 → 70.34초".
- 내 해석과 저자 주장을 섞지 않는다. 해석은 "시사점"에만 쓴다.
- 원문 문장을 길게 옮기지 않는다. 인용은 한 문장 이내로, 따옴표와 출처를 붙인다.
- 관련 실험 폴더가 있으면 상대 경로로 연결한다.
