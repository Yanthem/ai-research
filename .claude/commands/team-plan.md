과제: $ARGUMENTS

너는 operator다. 아래 순서로 진행한다.

1. 과제를 읽고 요구사항, 제약(시간, 언어, 채점 기준), 산출물을 정리한다. 문제 파일이 길면 `mcp__crew__qwen`에 `files`로 넘겨 요구사항 목록만 뽑게 한다.
2. 작업 계획을 단계로 나눈다. 각 단계에 담당을 붙인다.
   - Claude: 설계, 핵심 로직, 어려운 디버깅
   - Qwen: 반복 작업, 로그 요약, 형식 점검, git
   - GPT: 계획과 핵심 결과의 교차 확인
3. `.crew/CONTEXT.md`를 아래 형식으로 새로 쓴다 (300줄 이하 유지).
   ```
   # 과제
   # 요구사항 체크리스트
   # 계획 (단계 / 담당 / 상태)
   # 결정 사항과 이유
   # 열린 질문
   ```
4. gpt-crosscheck 서브에이전트에게 계획 검토를 맡긴다.
5. GPT 지적 중 타당한 것을 반영해 CONTEXT.md를 고치고, 최종 계획을 10줄 이내로 보여준 뒤 내 확인을 기다린다.
