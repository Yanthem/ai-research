# DCI: Beyond Semantic Similarity: Rethinking Retrieval for Agentic Search via Direct Corpus Interaction

- arXiv 2605.05242 (v1, 2026-05-03). Li 외 19명 (Texas A&M, Waterloo, UCSD, Stanford, UW, UIUC, Verdent AI, Lambda). Jimmy Lin, Yejin Choi, James Zou 참여.
- 코드: github.com/DCI-Agent/DCI-Agent-Lite (MIT)
- 읽은 날: 2026-11-24 (HTML/PDF 원문, 그림 1 표는 본문 서술로 확인)

## 한 줄
임베딩·벡터 인덱스·검색 API를 모두 빼고, 에이전트에게 bash와 read만 주어 원문 폴더를 rg로 직접 탐색하게 하면 같은 모델에서 RAG보다 정확하고 싸다.

## 방법
- DCI-Agent-Lite: Pi 하네스, 도구는 bash와 read. GPT-5.4 nano(추론 high). 최대 300턴.
- DCI-Agent-CC: Claude Code 기본 설정(웹 검색·서브에이전트 끔). Claude Sonnet 4.6. 내장 Grep이 호출의 33%.
- 컨텍스트 관리 L0~L4: 도구 출력 50K/20K자 자르기, 누적 24만 자 넘으면 최근 12턴만 남김(L3), 요약(L4).
- 프롬프트(부록 C): rg/bash만, 병렬 검색, 경로 인용, 답·확신도 형식.

## 주요 수치 (원문 표)
- BrowseComp-Plus(830문항, 10만 문서): Sonnet 4.6 + Qwen3-Emb-8B 검색 69.0%, $1,440 → DCI-CC 80.0%, $1,016. 같은 모델 비교라 가장 믿을 만한 결과.
- 같은 100문항 부분집합, GPT-5.4 nano: BM25 32 / Qwen3 임베딩 45 / read+grep 61 / 열린 bash 73. 도구 호출은 bash 쪽이 2배(35 vs 18).
- 멀티홉 QA 평균: DCI-Lite 68.0, DCI-CC 83.0 vs ASearcher-14B 52.3 (데이터셋당 50문항).
- IR NDCG@10 평균: DCI-Lite 56.7, DCI-CC 68.5 vs ReasonRank-32B 47.0.
- 명령 분포(Lite, 3,168개): `rg | head` 56%, `rg | rg` 21%, wc 8%.

## 비판적으로 볼 점
1. 다른 비교 대부분은 모델이 다르다. QA 기준선은 7B~32B 오픈 모델, DCI는 최신 API 모델이라 인터페이스 효과와 모델 효과가 섞인다.
2. 반복 실행·분산·신뢰구간이 없다. 100문항에서 1~5점 차이는 1~5문항이다.
3. 코퍼스가 커지면 약해진다(RQ4): 10만→20만 문서에서 도구 호출 38.5→86.9, 정확도 -13.6점, 40만에서 37.5%. "확장된다"는 서술과 긴장 관계이고, 이것이 DR-DCI의 출발점이다.
4. "coverage"의 정의가 RAG(순위 스니펫)와 DCI(로그에 나온 경로·줄)에서 달라 같은 잣대가 아니다.
5. 한국어 등 다국어, 소형·로컬 모델은 다루지 않는다. 별도 한계(Limitations) 절이 없다.
